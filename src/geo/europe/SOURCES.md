# European basemaps — sources, licences, processing

Files in this folder are generated by `npm run build:geo`
(`scripts/build-europe-geo.mjs`, mapshaper 0.7.80). Raw downloads are cached in
`./geo-raw/` (git-ignored). Build parameters of the current files:
`build-info.json`.

| File | Content | Features | Size |
|---|---|---|---|
| `countries.topo.json` | Countries (context + country level) | 95 | ~46 KB |
| `nuts1.topo.json` | NUTS 1 — incl. 13 French régions, 3 Belgian regions | 111 | ~36 KB |
| `nuts2.topo.json` | NUTS 2 — incl. 10 Belgian provinces + Brussels | 290 | ~77 KB |
| `nuts3.topo.json` | NUTS 3 — incl. 96 French départements | 1 329 | ~300 KB |

All files are TopoJSON (one object named `countries` / `nuts1` / `nuts2` /
`nuts3`), WGS84 lon/lat (EPSG:4326), quantization 20 000. Properties:
`id`, `name`, `cntr`, `level` (NUTS) and `id`, `name`, `nameFr`, `continent`
(countries).

## 1. Regions — Eurostat GISCO, NUTS 2024

- Dataset: *Territorial units for statistics (NUTS)*, version **NUTS 2024**
  (GISCO release 2024-06-04, last attribute fix 2026-09-25), scale **1:10 Million**,
  levels 1, 2 and 3, polygons (`RG`), EPSG:4326, GeoJSON.
- URLs:
  - https://gisco-services.ec.europa.eu/distribution/v2/nuts/geojson/NUTS_RG_10M_2024_4326_LEVL_1.geojson
  - https://gisco-services.ec.europa.eu/distribution/v2/nuts/geojson/NUTS_RG_10M_2024_4326_LEVL_2.geojson
  - https://gisco-services.ec.europa.eu/distribution/v2/nuts/geojson/NUTS_RG_10M_2024_4326_LEVL_3.geojson
  - (SVG cartons of France / Belgium only: same at 1:1 Million, `NUTS_RG_01M_2024_4326_LEVL_{1,2,3}.geojson`)
- Landing page: https://ec.europa.eu/eurostat/web/gisco/geodata/statistical-units/territorial-units-statistics
- Coverage note: NUTS 2024 has **no United Kingdom**; Ukraine is level 0 only;
  Bosnia-Herzegovina is at levels 1–2 only. Where a NUTS level has no coverage,
  the countries layer is drawn underneath (and used for point → region lookup).
- **Licence (Eurostat/GISCO download conditions)**: the Commission grants a
  non-exclusive, non-transferable right to use and process the data **on
  condition that the data are not used for commercial purposes** and that the
  source is acknowledged. *“If you intend to use the data commercially, please
  contact EuroGeographics for information about their licence agreements.”*
- **Mandatory attribution** (map legend and introductory page):
  - FR: **© EuroGeographics pour les limites administratives**
  - EN: **© EuroGeographics for the administrative boundaries**
  - The map mode prints it under the map (`EUROPE_ATTRIBUTION_FR`).

> ⚠️ Reporting 4D is a commercial product: before shipping the NUTS layers to
> paying customers, obtain a EuroGeographics licence (or switch the region layers
> to a source with an open commercial licence). The countries layer below has no
> such restriction.

## 2. Countries — Natural Earth admin-0, 1:50m

- Dataset: Natural Earth *Admin 0 – Countries*, 1:50m, version **5.2.0-pre**
  (GitHub `nvkelso/natural-earth-vector`, branch `master`).
- URL: https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_50m_admin_0_countries.geojson
- Home: https://www.naturalearthdata.com/downloads/50m-cultural-vectors/50m-admin-0-countries-2/
- **Licence: public domain** (https://www.naturalearthdata.com/about/terms-of-use/).
  No attribution required; credited as “Natural Earth” anyway.
- Note: Natural Earth shows *de facto* boundaries (e.g. Northern Cyprus `CYN`,
  Kosovo `XK`); NUTS units follow EU statistical boundaries.

## 3. Processing (mapshaper)

| Step | NUTS 1/2/3 | Countries |
|---|---|---|
| Overseas filter | drop `NUTS_ID` starting `FRY` (French DOM), `ES7` (Canarias), `PT2` (Açores), `PT3` (Madeira), `NO0B` (Svalbard & Jan Mayen) | drop Greenland |
| Clip | `-clip bbox=-25,34,45,72 remove-slivers` | `-clip bbox=-40,22,95,80 remove-slivers` (wider so cut edges stay off-screen) |
| Erase islands kept inside mainland shapes | Jan Mayen box | Canarias, Madeira, Açores, Jan Mayen boxes |
| Simplify | `-simplify weighted keep-shapes`: 12 % (NUTS 1, 2), 10 % (NUTS 3) | 14 % |
| Clean | `-clean` (repairs intersections from simplification) | idem |
| Output | `format=topojson quantization=20000` | idem |

Keep overseas territories (writes elsewhere, nothing clipped):
`node scripts/build-europe-geo.mjs --keep-overseas --out /tmp/europe-overseas`.

**Winding / bounds check (d3 spherical convention)**: mapshaper writes CW outer
rings, which is what d3-geo expects. The build fails if any feature has
`d3.geoArea > 2π` (inside-out ring) or `d3.geoBounds` wider than 160° / taller
than 70° — the symptom of the earlier FR-17/65/85 bug. `src/geo/europe.ts`
also rewinds at runtime any feature whose area exceeds a hemisphere.

## 4. Static SVG cartons (`docs/maps/*.svg`)

Generated by `npm run build:maps` (`scripts/build-map-svgs.mjs`), previews by
`python3 scripts/render-map-previews.py` (CairoSVG) → `docs/maps/previews/*.png`.

| SVG | Source | Simplification | Projection |
|---|---|---|---|
| `europe-countries.svg` | Natural Earth 1:50m | 20 % | Azimuthal equal-area, centre 10°E 52°N |
| `europe-nuts2.svg` | GISCO NUTS 2024 1:10M L2 (+ NE for non-NUTS countries) | 20 % | idem |
| `france-regions.svg` | GISCO NUTS 2024 1:1M L1 (FR, excl. FRY) | 10 % | Conic conformal, parallels 44°/49°N, 3°E (≈ Lambert-93) |
| `france-departements.svg` | GISCO NUTS 2024 1:1M L3 (FR, excl. FRY); `data-dept` = INSEE code | 10 % | idem |
| `belgium-regions.svg` | GISCO NUTS 2024 1:1M L1 (BE) | 25 % | Conic conformal, parallels 49.83°/51.17°N, 4.37°E (≈ Lambert 72) |
| `belgium-provinces.svg` | GISCO NUTS 2024 1:1M L2 (BE) | 25 % | idem |

Each region is a `<path id="…" data-id="NUTS_ID|ISO2" data-name="…">` with a
`<title>`; title and attribution are in `<g id="title">` / `<g id="attribution">`
(the attribution must stay visible for the GISCO-based cartons).
