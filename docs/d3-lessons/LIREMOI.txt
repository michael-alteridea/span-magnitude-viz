Sur iPad
--------
1. Copie ce dossier dans Fichiers (iCloud / OneDrive / « Sur mon iPad »).
2. Ouvre index.html avec Safari (partage → Safari) ou un lecteur HTML offline.
3. Pas besoin de réseau : D3 est local.

Sur Windows
-----------
Double-clic index.html dans le navigateur, ou sers le dossier :
  npx serve .
