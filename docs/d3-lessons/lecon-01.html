Données → DOM

D3 = Data-Driven Documents. On branche un tableau JS sur des éléments HTML/SVG.

M
J’ai des chiffres… comment ils deviennent des barres ?
D3
Chaque valeur = un nœud DOM. D3 fait le mariage : data ↔ éléments.
Pense « une ligne de données → une marque visuelle ». C’est le mantra de tout le cours — et de span-magnitude.

Labo live

Appuie sur Binder : on crée une <div> par nombre, largeur = valeur × 8 px.

#viz — barres HTML
const data = [12, 28, 45, 33, 19];
d3.select("#viz").selectAll("div.bar")
  .data(data)
  .join("div")
  .attr("class", "bar")
  .style("width", d => d * 8 + "px")
  .text(d => d);
