Formes SVG

rect, circle, line, path — dessiner des marques à partir des données.

D3
SVG = scène vectorielle. Chaque forme a des attributs (x, y, width, r, d…).
Pour span-magnitude : un rect (ou arc) dont width = durée et height = intensité.

Labo live

Trois projets jouets : durée (mois) → largeur, budget → hauteur.

rect = span × magnitude
svg.selectAll("rect").data(projets).join("rect")
  .attr("x", 20).attr("y", (d,i) => 20 + i*55)
  .attr("width", d => x(d.mois))
  .attr("height", d => y(d.budget))
  .attr("fill", "#d62839");
