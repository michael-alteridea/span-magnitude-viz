Joins enter / update / exit

Le cœur de D3 : synchroniser la troupe DOM avec le tableau de données.

D3
enter = nouveaux · update = déjà là · exit = plus dans les data → on retire.
.data(arr).join("circle") gère les trois cas. Avec une key, l’identité survit au reorder.

Labo live

cercles liés par id

n = 3

svg.selectAll("circle").data(items, d => d.id)
  .join(
    enter => enter.append("circle").attr("r", 0)
      .call(e => e.transition().attr("r", 18)),
    update => update,
    exit => exit.transition().attr("r", 0).remove()
  );
