Échelles

scaleLinear : domain (données) → range (pixels). Le GPS de la viz.

M
Mes projets durent 3 à 48 mois… comment ça tient en 300 px ?
D3
scaleLinear().domain([3,48]).range([0,300]) — magie proportionnelle.

Labo live

Glisse (ou tape) pour changer la valeur. L’échelle place le curseur.

domain [0,100] → range [20,300]
const x = d3.scaleLinear().domain([0, 100]).range([20, 300]);
dot.attr("cx", x(valeur));
